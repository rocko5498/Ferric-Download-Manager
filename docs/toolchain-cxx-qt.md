### Troubleshooting (Windows-specific)

- **Windows `MAX_PATH` (260 char) build failure.** Building from a deeply
  nested/long path (e.g. this repo's own `R:\Rust Project\Rust.net Download
  Manager\...\examples\qml_minimal\build\x64\Release\cargo\...\out\cxx-qt-build\
  initializers\qml_module_com_kdab_cxx_qt_demo\call-initializers.cpp`) fails
  with `C1083: Cannot open source file` — the generated intermediate path from
  `cxx-qt-build`'s codegen (build dir + target triple + crate hash + qml
  module URI + generated filename) easily exceeds 260 chars once combined with
  a long project path. **Fix: build from a short root path** (e.g.
  `R:\cxxqt-min\...` instead of nesting inside this repo) — not a code fix,
  a path-length workaround. Long Path support (`git config core.longpaths
  true` / Windows 10+ policy) may also help but was not needed once the path
  was shortened; not verified as a full alternative fix.
- **Git symlinks checked out as plain text files.** `examples/qml_minimal_plugin/rust/src`
  in the upstream repo is a symlink to `../../qml_minimal/rust/src`. Windows
  git (without `core.symlinks=true`, which needs admin/Developer Mode) checks
  this out as a small text file *containing the target path string*, not a
  real directory — breaks `cargo metadata` for the whole workspace (```error:
  can't find library `qml_minimal_plugin`, rename file to `src/lib.rs````)
  even though `qml_minimal_plugin` isn't the crate you're building, because
  it's a sibling workspace member in the repo's root `Cargo.toml`. Fix:
  delete the placeholder file and `cp -r` the real target directory in its
  place, or enable symlinks before cloning (`git config --global
  core.symlinks true`, requires Developer Mode or admin on Windows).
- All required Qt components (`Core Gui Qml QuickControls2 QuickTest Test`
  + `QmlImportScanner`) were already present from the FQT-001 aqt install —
  no extra `aqt install-qt -m ...` module needed for this example.

**Known-good version:** cxx-qt **0.9.1**, tag `v0.9.1` in the upstream repo,
against Qt 6.8.3 / MSVC 2022 (19.44.35228.0) / CMake 4.3.3 / Rust 1.96.0.
