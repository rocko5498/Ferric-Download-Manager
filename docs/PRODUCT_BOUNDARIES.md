# Ferric product principles

Ferric is a secure, transparent, open-source download workstation. Its code, wording, interface and architecture are original.

## Rules

- Do not copy another product's names, logos, icons, bitmap assets, dialog text, help files or strings.
- Do not use anyone else's trademarks in the product interface, assets, installer text or marketing.
- Do not implement DLL injection, browser patching, man-in-the-middle interception, kernel or network drivers, scraping of browser cookie databases, or capture paths that need administrator rights.
- Feature categories may overlap with other download managers, but the implementation must be Ferric's own.

## What sets Ferric apart

- Transparent network diagnostics: chunk map, per-connection speed, retry reasons, server and CDN behaviour, resume confidence, and URL-expiry explanations.
- Safer browser integration: an extension plus native messaging, with explicit user consent.
- Deterministic diagnosis: structured rules first; an optional local model may only narrate the facts.
- Strong official-build security: signing, a reproducible build path, extension-ID pinning, and clear warnings for unofficial or debug builds.

## Positioning

Preferred wording: "secure open-source download workstation", "transparent download manager", "network-aware download manager".
